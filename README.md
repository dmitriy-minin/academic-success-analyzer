#  Нейронная сеть для аналитики успеваемости студентов

Проект реализует полносвязную нейронную сеть на PyTorch, которая принимает
11 числовых характеристик студента и возвращает **рекомендуемую оценку** (от 0 до 100).

## Входные значения

| № | Признак | Описание | Тип |
|---|---------|----------|-----|
| 1 | `num_grades` | Количество оценок | целое |
| 2 | `avg_grade` | Средняя оценка (0–100) | вещественное |
| 3 | `grade_trend` | Тренд (разница между оценками, может быть отрицательным) | вещественное |
| 4 | `num_absences` | Количество пропусков | целое |
| 5 | `unexcused_absences` | Неуважительные пропуски | целое |
| 6 | `num_tardies` | Количество опозданий | целое |
| 7 | `num_tests_completed` | Количество пройденных тестов | целое |
| 8 | `avg_time_on_tests` | Среднее время на тест (минуты) | вещественное |
| 9 | `avg_test_attempts` | Среднее число попыток на тест | вещественное |
| 10 | `num_assignments_submitted` | Количество сданных заданий | целое |
| 11 | `avg_time_on_assignments` | Среднее время на задание (минуты) | вещественное |

**Выход:** одно число – рекомендуемая оценка в диапазоне **[0.0, 100.0]**.

## Архитектура нейронной сети

```
Вход (11 нейронов)
       ↓
Linear(11 → 64)  + BatchNorm + ReLU + Dropout(0.2)
       ↓
Linear(64 → 128) + BatchNorm + ReLU + Dropout(0.2)
       ↓
Linear(128 → 64) + BatchNorm + ReLU + Dropout(0.2)
       ↓
Linear(64 → 32)  + ReLU
       ↓
Linear(32 → 1)   + Sigmoid × 100
       ↓
Выход (1 нейрон, значение в [0, 100])
```

- **BatchNormalization** – стабилизирует обучение и ускоряет сходимость  
- **Dropout** – регуляризация, снижает переобучение  
- **Sigmoid × 100** – гарантирует, что выход всегда в допустимом диапазоне  
- **Инициализация Xavier** – оптимальный старт весов для сетей с ReLU

| Фактор | Вес | Влияние |

| Тренд оценок | 10 % | Положительное |

| Опоздания | 5 % | Штраф |

##  Обучение

```bash
python train.py
```

### Параметры командной строки

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `--dataset` | `dataset.csv` | Путь к датасету |
| `--epochs` | `150` | Число эпох обучения |
| `--lr` | `0.001` | Скорость обучения (learning rate) |
| `--batch-size` | `16` | Размер мини-батча |
| `--dropout` | `0.2` | Вероятность Dropout |
| `--model-out` | `model.pth` | Файл сохранения модели |
| `--scaler-out` | `scaler.pkl` | Файл сохранения нормализатора |

### Примеры

```bash
# Стандартное обучение
python train.py

# Больше эпох, меньше скорость обучения
python train.py --epochs 300 --lr 0.0005

# Больший батч, меньше Dropout
python train.py --batch-size 32 --dropout 0.1
```

### Разбивка данных

- **70 %** – обучающая выборка (70 примеров)  
- **15 %** – валидационная выборка (15 примеров)  
- **15 %** – тестовая выборка (15 примеров)  

### Процесс обучения

Скрипт выводит метрики каждые 10 эпох:

```
Эпоха    1/150 | Train MSE:  394.40 | Val MSE:  114.30 | Val MAE:  8.64
Эпоха   10/150 | Train MSE:   97.69 | Val MSE:   73.62 | Val MAE:  7.27
...
Эпоха  150/150 | Train MSE:   41.84 | Val MSE:   25.10 | Val MAE:  3.89

   Результат на тестовой выборке:
   MSE : 16.85
   MAE : 3.00  (средняя абсолютная ошибка в баллах)
   RMSE: 4.11
```

**Метрики:**
- **MSE** (Mean Squared Error) – среднеквадратичная ошибка; функция потерь при обучении  
- **MAE** (Mean Absolute Error) – средняя абсолютная ошибка в баллах; основная метрика качества  
- **RMSE** (Root MSE) – корень из MSE, имеет ту же размерность, что и оценка  

После обучения сохраняются файлы `model.pth` и `scaler.pkl`.

## Нормализация данных

Все признаки нормализуются методом **StandardScaler** (z-нормализация):

```
z = (x − mean) / std
```

- Параметры (`mean`, `std`) вычисляются **только** на обучающей выборке  
- Валидационная и тестовая выборки нормализуются с теми же параметрами  
- При инференсе используется тот же `scaler.pkl`, что и при обучении  
- Это предотвращает «утечку данных» (data leakage)

## Описание файлов

### `model.py`
Содержит класс `StudentPerformanceNet` и список `FEATURE_NAMES`.  
Импортируется в `train.py` и `predict.py`.

### `dataset.py`
Три функции:
- `load_dataset(filepath)` – читает CSV, возвращает `(X, y)`  
- `split_dataset(X, y)` – делит 70/15/15  
- `normalize_features(X_train, X_val, X_test)` – нормализует и возвращает скейлер  

### `generate_dataset.py`
Генерирует 100 синтетических студентов с реалистичными признаками и целевыми оценками.

### `train.py`
Полный цикл обучения: загрузка → нормализация → обучение → оценка → сохранение.

### `predict.py`
Три режима работы: интерактивный, через аргументы, пакетный.

### `model.pth`
Чекпоинт PyTorch. Содержит:
- `model_state_dict` – веса модели  
- `dropout_rate` – параметр Dropout (нужен при загрузке)  
- `feature_names` – список признаков  

### `scaler.pkl`
Сериализованный объект `StandardScaler`. Обязателен для корректного инференса.

## Как можно улучшить качество

1. **Больше данных** – заменить синтетический датасет реальными данными (≥ 500 примеров)  
2. **Больше эпох** – использовать `--epochs 300` или `--epochs 500`  
3. **Подбор гиперпараметров** – экспериментировать с `--lr`, `--batch-size`, `--dropout`  
4. **Кросс-валидация** – для малых датасетов использовать k-fold  
5. **Feature engineering** – добавить новые признаки (например, оценка × посещаемость)

## Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `FileNotFoundError: model.pth` | Модель не обучена | Запустите `python train.py` |
| `FileNotFoundError: dataset.csv` | Датасет не создан | Запустите `python generate_dataset.py` |
| `KeyError: 'num_grades'` | Неверные заголовки в CSV | Проверьте порядок столбцов |
| `ValueError: expected 11 values` | Неверное число признаков | Передайте ровно 11 чисел |
